Cómo conseguir tu clave

En la web de ElevenLabs. Los botones están en inglés, como aquí.

  1. Entra en ElevenLabs

    Inicia sesión, o crea tu cuenta gratis si aún no tienes.

    Abrir ElevenLabs

  2. Ve a Developers → API Keys

    Abajo a la izquierda, en el menú, pulsa Developers. Arriba, abre la pestaña API Keys.

    Developers
    API Keys

  3. Pulsa Create Key

    Ponle un nombre que reconozcas, por ejemplo Vídeos.

  4. Marca solo estos permisos

    Deja Restrict Key encendido y da acceso solo a esto. Todo lo demás, en No Access.

    Create API Key

    Restrict Key
    Text to Speechpara hacer la vozAccess
    Voicespara escuchar y elegir tu voz, y añadir las de la bibliotecaWrite
    Userpara saber cuántos caracteres te quedanRead
    Todo lo demásNo Access
    Si quieres, pon también un límite de créditos: la clave nunca gastará más. ¿Prefieres no complicarte? Apaga Restrict Key: también funciona, pero la clave podrá hacer cualquier cosa en tu cuenta.

  5. Crea la clave y cópiala ya

    Pulsa Create y copia la clave que aparece. Empieza por sk_. Pégala en el recuadro de esta página.
