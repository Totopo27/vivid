# Los sonidos

Solo se usan estos: todos se han oído en reels publicados, y los marcados con ✓ sonaron en vídeos aprobados con los
efectos puestos (como la estrella verde). En `sonidos.js`, cada uno se pide por su nombre (sin la extensión).

| Nombre | Qué es | Para qué |
|---|---|---|
| `aire` ✓ | un aire corto y suave, como algo que pasa rápido cerca | la cámara que se mueve, algo que entra o pasa |
| `empujon` ✓ | un aire fuerte que se acerca y acaba de golpe | lanzarse hacia algo, desplomarse, apretarse |
| `estallido` ✓ | un estallido grande y su retumbar | algo que revienta o muere con un fogonazo; al revés, una subida grave |
| `roca` ✓ | un golpe seco de piedra con trocitos | algo de piedra que se parte o choca |
| `golpe` ✓ | un golpe sordo y firme | algo que choca o se posa con fuerza |
| `golpe-hondo` ✓ | un golpe sordo más hondo | el choque más grande |
| `clic` ✓ | un clic corto y limpio | algo que aparece, se marca o se para |
| `tic` ✓ | un tic de traqueteo | un número que corre; algo que traquetea |
| `sube` ✓ | un aire corto hacia arriba | algo que sube o se va |
| `late` ✓ | un clic corto, como el de una pajita | el latido de la cosa principal (siempre el mismo) |
| `aprieta` ✓ | algo blando que se aplasta | apretar, aplastar |
| `metal` ✓ | un golpe metálico fuerte | algo de metal que choca o encaja |
| `madera` ✓ | un golpe de madera | algo que cae sobre madera |
| `toque` ✓ | un toque de dedo en un cristal | tocar una pantalla o un cristal |
| `desliza` ✓ | una pieza de metal que se desliza | algo que se desliza |
| `cristal` | un cristal que se posa, claro y corto | algo de cristal que se posa o choca |
| `muro` | un bloque pesado que cae en su sitio | algo muy pesado que se para |
| `cruje` | algo de metal que se aplasta con presión | apretar hasta romper |
| `enganche` | un clac metálico pequeño | algo pequeño de metal que encaja |
| `cuadro` | un marco de madera pesado sobre una mesa | algo de madera pesado que se posa |
| `lingote` | lingotes de metal que caen unos sobre otros | algo denso de metal que cae |
| `madera-rota` | una mesa de madera que se parte | madera que se rompe |
| `papel` | un periódico que cae plano sobre una mesa | papel, cartas, fotos |
| `pelota` | una pelota que bota dos veces | algo que bota |
| `timbre` | un timbre de bicicleta, dos veces | un aviso alegre |
| `pitido` | un pitido electrónico corto | un aparato que mide o avisa |
| `hueco` | un golpe metálico hueco (un casco) | algo hueco de metal |
| `canon` | un cañonazo grave con eco | un golpe enorme a lo lejos |
| `tierra` | un salto que cae sobre tierra | algo que cae al suelo blando |
| `aviso` | una notificación de móvil | un mensaje que llega |

Para añadir uno: un archivo corto (`.mp3` o `.wav`) en esta carpeta, con un nombre de lo que suena, y su fila aquí.
Solo sonidos que se puedan usar en vídeos publicados (propios o con licencia que lo permita).
